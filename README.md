# 장점 칭찬 수업 도우미

초등 공개수업(장점 찾기·칭찬하기) 전개를 3단계로 진행하는 수업 도구.
브라우저만 있으면 되고 설치·로그인이 필요 없습니다.

**바로 열기 → https://today119.github.io/praise-timer/**

## 수업 전개

| 단계 | 활동 | 화면에 들어간 기능 |
|---|---|---|
| 1 | 동기유발 · 책 읽기 | 읽기 타이머(기본 10분), 책 제목, 생각할 질문 3개 크게 표시 |
| 2 | 나의 장점 쓰기 | 쓰기 타이머(기본 5분) + 「곧 끝나요」 경고, 장점 낱말 띠, 다 쓴 사람 카운터 + 진행 막대 |
| 3 | 서로 물어보고 조사하기 | 라운드 타이머(2분 × 10), 묻기/칭찬 대사, 라운드 점, 자리 이동 안내 + 카운트다운 |

상단 단계 띠를 눌러 언제든 이동할 수 있고, 단계마다 화면 색이 바뀝니다(보라 → 초록 → 주황).
「다음 단계 →」로 넘기면 전환 안내 화면이 뜨고 닫는 즉시 타이머가 시작됩니다.

## 공통 기능
- 「낱말」 버튼 — 장점 낱말 전체화면으로 크게 보기
- 전체화면 버튼, 화면 꺼짐 방지(수업 중 화면이 안 꺼짐)
- 종소리·경고음 (설정에서 끌 수 있음)
- 설정은 이 브라우저에 자동 저장 — 수업 전에 한 번만 맞추면 됨

## 단축키
`Space` 시작/멈춤 · `1` `2` `3` 단계 이동 · `→` 다음(3단계에서는 자리 이동) · `←` 이전 단계 · `↑` 시간 추가 · `F` 전체화면 · `Esc` 닫기

## 3단계 자리 배치
책상을 두 줄로 마주 보게 놓고 **안쪽 줄은 고정**, **바깥줄만 오른쪽으로 한 칸** 이동.
맨 끝 학생은 반대쪽 끝으로. 학급 인원의 절반만큼 라운드를 돌면 모두가 서로 한 번씩 만납니다.
홀수 학급이면 한 자리를 3명으로 만들거나 교사가 한 자리에 들어가면 됩니다.
