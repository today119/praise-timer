# 반짝반짝 나를 발견하는 시간

4학년 학부모 공개수업 「나의 장점을 발견하며 시작하는 진로 여행」 진행 도구.
수업 자료(PPT)의 흐름과 활동지를 그대로 화면으로 옮겼습니다. 설치·로그인 없이 브라우저만 있으면 됩니다.

**바로 열기 → https://today119.github.io/praise-timer/**

## 수업 전개

| 단계 | 활동 | 화면 기능 |
|---|---|---|
| 1 | 그림책 「내가 너라서 좋아」 | 읽기 타이머, 발문 2개, 오늘의 학습 목표 |
| 2 | 활동1 「내가 나라서 좋아!」 | 활동 타이머, 문장 틀(내가 ○○라서 좋아 / 왜냐하면 ○○ 때문이야), 할 일 2가지, 다 쓴 사람 카운터 |
| 3 | 활동2 「당근! 장점 거래하실래요?」 | 거래 타이머, 활동 방법 4단계, **장점 온도계(거래 1회당 +10℃)**, 「당근왔숑!」 신호 |
| 4 | 정리 「가족의 거울에 비친 나」 | 편지 쓰기 타이머, 세 거울(내가·친구가·가족이 바라본 나) |

상단 단계 띠로 언제든 이동할 수 있고, 단계마다 화면 색이 바뀝니다. (보라 → 분홍 → 주황 → 초록)

활동 2를 뺀 나머지 단계에서는 타이머를 작게 두고 **수업 자료 그림과 글이 화면의 중심**이 되도록 했습니다.
활동 2는 남은 시간이 중요하므로 타이머를 크게 유지합니다.

## 장점 힌트 카드
「힌트 카드」 버튼을 누르면 수업 자료의 힌트 카드가 전체화면으로 뜹니다.
**공부·도전 / 성격·마음 / 친구·사람 / 생활·태도** 4범주 48개. 설정에서 내용을 자유롭게 바꿀 수 있고,
평소에는 화면 아래에 띠로 천천히 흘러갑니다.

## 「당근왔숑!」 신호음
설정에서 고를 수 있습니다.
1. **유튜브 영상 재생**(기본) — 당근마켓 알림음 영상을 유튜브 공식 임베드 플레이어로 재생합니다.
   **화면에는 아무것도 나오지 않고 소리만 납니다.** 영상 주소·시작 시간(초)·재생 길이(초)를 설정에서 바꿀 수 있고,
   설정 화면의 미리보기로 쓸 부분을 찾을 수 있습니다. 영상 화면을 보여 주고 싶으면 설정에서 켤 수 있습니다.
2. **음성으로 말하기** — 브라우저 음성합성이 "당근왔숑!"이라고 말합니다. 문구도 바꿀 수 있습니다.
3. **당근 차임** — 마림바 느낌의 도·미·솔 3음
4. **종소리**
5. **내 소리 파일** — mp3·m4a(2MB 이하)를 직접 넣으면 그 소리로 울립니다. 브라우저에 저장돼 다음에도 유지됩니다.

> 유튜브 재생은 공식 임베드 플레이어를 그대로 쓰는 방식이라 문제가 없습니다. 영상에서 오디오만 추출해 파일로 올리는 것은 하지 않았습니다.
> 학교 인터넷이 유튜브를 막고 있으면 플레이어가 준비되지 않는데, 그때는 자동으로 「당근 차임」이 대신 울립니다.

## 수업 자료 그림
수업 PPT의 그림을 그대로 넣었습니다. 그림을 누르면 전체화면으로 크게 보입니다.

| 위치 | 자료 |
|---|---|
| 1단계 | 그림책 표지 |
| 2단계 | 활동1 활동지, 「장점 4칸」 |
| 3단계 | 「당근! 장점 마켓」 안내 |
| 4단계 | 세 거울(내가·친구가·가족이 바라본 나) |
| 힌트 카드 | 자료 원본 이미지 ↔ 글자 크게 보기 전환 |

> 1단계의 그림책 표지는 출판사 저작물입니다. 수업용으로 쓰는 표지 이미지이며, 문제가 되면 `img/cover.jpg` 참조를 지우면 됩니다.

## 그 밖의 기능
- 전체화면 버튼, 화면 꺼짐 방지(수업 중 화면이 안 꺼짐)
- 「곧 끝나요」 경고음 + 빨간 글씨
- 모든 시간·문구·인원·힌트 카드 내용을 설정에서 수정 → 브라우저에 자동 저장

## 단축키
`Space` 시작/멈춤 · `1` `2` `3` `4` 단계 이동 · `→` 다음(3단계에서는 당근왔숑) · `←` 이전 단계 · `↑` 시간 추가 · `H` 힌트 카드 · `F` 전체화면 · `Esc` 닫기

## 활동2 자리 배치
책상을 두 줄로 마주 보게 놓고 **안쪽 줄은 고정**, **바깥줄만 오른쪽으로 한 칸** 이동.
맨 끝 학생은 반대쪽 끝으로. 학급 인원의 절반만큼 거래하면 모두가 서로 한 번씩 만납니다.
홀수 학급이면 한 자리를 3명으로 만들거나 교사가 한 자리에 들어가면 됩니다.
