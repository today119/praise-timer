# 장점 칭찬 타이머

초등 공개수업용 활동 진행 도구. 브라우저만 있으면 되고 설치·로그인이 필요 없습니다.

**바로 열기 → https://today119.github.io/praise-timer/**

## 기능
- 라운드 타이머(기본 2분 × 10라운드), 남은 시간 링 + 경고 표시
- 라운드 종료 시 「자리를 옮겨요!」 안내 + 이동 카운트다운 + 종소리
- 묻는 말 / 칭찬하는 말 대형 표시
- 장점 낱말 띠(흐르는 배너) + 「낱말 크게」 전체화면 보기
- 설정에서 라운드 수·시간·문구·낱말 수정 (브라우저에 자동 저장)
- 전체화면 버튼, 화면 꺼짐 방지

## 단축키
`Space` 시작/멈춤 · `→` 다음 라운드 · `↑` +30초 · `F` 전체화면 · `Esc` 닫기

## 자리 배치
책상을 두 줄로 마주 보게 놓고 **안쪽 줄은 고정**, **바깥줄만 오른쪽으로 한 칸** 이동.
맨 끝 학생은 반대쪽 끝으로. 학급 인원의 절반만큼 라운드를 돌면 모두가 서로 한 번씩 만납니다.
