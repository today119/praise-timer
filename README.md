# 반짝반짝 나를 발견하는 시간

4학년 학부모 공개수업 「나의 장점을 발견하며 시작하는 진로 여행」 진행 도구.
**수업 PPT를 따로 띄울 필요 없이 이 앱 하나로 수업을 진행합니다.** 자료 슬라이드와 활동 화면이 한 흐름으로 이어집니다.

**바로 열기 → https://today119.github.io/praise-timer/**

## 어떻게 쓰나
화면 아래 **← 이전 / 다음 →** 로 넘깁니다. `→` `Enter` 로도 넘어가고, `←` 로 돌아갑니다.
활동 화면에서는 아래에 **타이머 칩**(`🕐 8:00 시작 +1분 ↺`)이 나타납니다. 활동이 아닌 슬라이드에서는 숨겨집니다.
숫자 `1` `2` `3` `4` 를 누르면 각 단계 첫 화면으로 바로 이동합니다.

## 활동 2 · 당근 장점마켓
거래 한 번이 끝날 때마다 **장점 온도가 +10℃** 오르고, 「당근왔숑!」 신호가 울린 뒤 다음 거래가 자동으로 시작됩니다.
「🥕 당근왔숑! →」 버튼으로 남은 시간과 상관없이 바로 넘길 수도 있습니다.

### 「당근왔숑!」 신호음
설정에서 고를 수 있습니다.
1. **유튜브 영상 재생**(기본) — 당근마켓 알림음 영상을 유튜브 공식 임베드 플레이어로 재생합니다.
   **화면에는 아무것도 나오지 않고 소리만 납니다.** 영상 주소·시작 시간(초)·재생 길이(초)를 바꿀 수 있고,
   설정 화면의 미리보기로 쓸 부분을 찾을 수 있습니다. 영상 화면을 보여 주고 싶으면 설정에서 켜세요.
2. **음성으로 말하기** — 브라우저 음성합성이 "당근왔숑!"이라고 말합니다.
3. **당근 차임** — 마림바 느낌의 도·미·솔 3음
4. **종소리**
5. **내 소리 파일** — mp3·m4a(2MB 이하)를 직접 넣으면 그 소리로 울립니다.

> 유튜브 재생은 공식 임베드 플레이어를 그대로 쓰는 방식입니다. 영상에서 오디오만 추출해 파일로 올리는 것은 하지 않았습니다.
> 학교 인터넷이 유튜브를 막고 있으면 자동으로 「당근 차임」이 대신 울립니다.

## 장점 힌트 카드
슬라이드 12번으로 흐름 안에 들어 있고, 상단 **「힌트 카드」** 버튼(`H` 키)으로 언제든 다시 띄울 수 있습니다.
**수업 자료 그대로 / 글자 크게** 두 가지로 볼 수 있습니다. 글자판의 48개 낱말은 설정에서 수정할 수 있습니다.

## 그 밖의 기능
- 슬라이드 그림을 누르면 전체화면으로 크게 보기
- 전체화면 버튼(`F`), 화면 꺼짐 방지
- 「곧 끝나요」 경고음 + 빨간 글씨
- 모든 시간·문구·인원·힌트 카드 내용을 설정에서 수정 → 브라우저에 자동 저장

## 단축키
`→`·`Enter` 다음 · `←` 이전 · `Space` (활동 화면에선 타이머 시작/멈춤, 그 밖엔 다음) · `↑` 시간 추가 · `1`~`4` 단계 이동 · `H` 힌트 카드 · `F` 전체화면 · `Esc` 닫기

## 활동 2 자리 배치
책상을 두 줄로 마주 보게 놓고 **안쪽 줄은 고정**, **바깥줄만 오른쪽으로 한 칸** 이동.
맨 끝 학생은 반대쪽 끝으로. 학급 인원의 절반만큼 거래하면 모두가 서로 한 번씩 만납니다.

> 슬라이드 그림은 수업 PPT에서 뽑은 것입니다. 2번 화면의 그림책 표지는 출판사 저작물이며, 빼려면 `img/book.jpg` 슬라이드를 덱에서 제거하면 됩니다.
